Museum Walk-Through

View the rooms in our museum and travel between them by selecting a room below or clicking the orange markers inside the 360° view. Click and drag to look around. Prefer a floor-plan overview? Try the interactive museum tour map.

Click and drag to look around. Use room buttons or orange markers to move between spaces.

How to Add This Walk-Through to WPBakery

  1. 1
    Open the Walk-Through (or Tour the Museum) page in WordPress

    Navigate to Pages → All Pages, find the destination page, and click Edit with WPBakery.

  2. 2
    Add a "Raw HTML" element

    Click the + button to add a new element. Search for Raw HTML and add it where the room-to-room walk-through should appear.

  3. 3
    Copy the walk-through code

    Open this HTML file in a text editor. Copy everything between the <!-- START: CMA Museum Walk-Through --> and <!-- END: CMA Museum Walk-Through --> comments. That gives you the <style>, markup, and <script> together.

  4. 4
    Paste into the Raw HTML block

    Paste the copied code into the Raw HTML element's content area. Do not wrap it in anything else — paste it exactly as-is.

  5. 5
    Save and preview

    Click Update, then preview. Room chips and orange markers should move you between 360° scenes. Drag to look around. The paste block already includes the Pannellum CDN CSS/JS tags.

⚠ Troubleshooting Tips
  • If the viewer appears but room buttons do nothing, WPBakery may be stripping <script> tags. Move the script into a Raw JS element.
  • If you see “360 viewer failed to load,” confirm the Pannellum CDN script is present above the walk-through and not blocked by CSP.
  • Styles are scoped under .cma-walk to avoid theme conflicts.
  • Room order and hotspot yaw/pitch live in the ROOMS array near the top of the script — edit links to retarget orange markers.
ⓘ Media URLs
  • ASSET_MODE defaults to "auto" — it uses the live media library on childrensmuseumatlanta.org (panos are same-origin there, so no CORS problem) and the bundled museum-tour-map/ files everywhere else (GitHub Pages preview/embed, local dev). No edits needed before pasting into CMA WordPress.
  • Force ASSET_MODE = "cdn" when pasting into a staging site on a non-CMA host, or ASSET_MODE = "local" to always use the public/museum-tour-map/ folder (upload it next to this HTML and point LOCAL_BASE at that path). Opening this HTML via file:// always uses CDN (Pannellum cannot XHR local files).
  • Companion floor-plan map widget: public/museum-tour-map.html — standalone at /Homepagev2/museum-tour-map.html.
