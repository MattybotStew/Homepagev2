Museum Walk-Through

View the rooms in our museum and travel between them by selecting a room below or clicking the orange markers inside the 360° view. Click and drag to look around. Prefer a floor-plan overview? Try the interactive museum tour map.

Developer Handoff — Working from the Zip

Package name: cma-museum-walk-through.zip. Unzip and keep the folder structure intact.

  1. 1
    What's in the zip

    museum-walk-through.html — main widget. museum-tour-map.html — companion floor-plan map. museum-tour-map/ — all 12 panorama files + floor plan PNG for local preview.

  2. 2
    Preview locally (optional)

    Open museum-walk-through.html in a browser. Keep museum-tour-map/ in the same folder — ASSET_MODE = "auto" uses those bundled files on localhost. Pannellum loads from jsDelivr; no build step.

  3. 3
    Deploy to WordPress (WP Engine / wpdev / production)

    Copy everything between <!-- START: CMA Museum Walk-Through --> and <!-- END: CMA Museum Walk-Through --> in museum-walk-through.html. Paste into a WPBakery Raw HTML block on /plan-your-visit/tour-the-museum/museum-walk-through/. Do not copy this instructions panel.

  4. 4
    Media library — usually no URL edits

    Leave ASSET_MODE = "auto". On WordPress the widget rewrites each room's cdn: URL to same-origin /wp-content/uploads/…. Panos must already exist at those paths (production uploads are listed in the ROOMS array). Copy production uploads to wpdev/staging if a pano 404s.

  5. 5
    When you do need to update URLs

    Edit the cdn: value for each room in the ROOMS array (~12 entries) only if uploads land at different filenames or paths than production. For static hosting (not WP), set ASSET_MODE = "local" and keep museum-tour-map/ next to the HTML — no cdn edits needed.

  6. 6
    Save, purge cache, test

    Update the page, purge WP Engine cache, preview logged-out. Room chips and orange markers should move between 360° scenes. Companion map: same START→END pattern in museum-tour-map.html.

⚠ Do not
  • Iframe the GitHub Pages preview or use WordPress Add from URL with github.io links — WP cannot sideload those files server-side.
  • Upload the zip's museum-tour-map/ folder via FTP for WP unless you explicitly set ASSET_MODE = "local" — default WP paste uses the media library.

How to Add This Walk-Through to WPBakery

  1. 1
    Open the Walk-Through page on the WP Engine WordPress site

    This widget is for the live CMA site (WP Engine), not this localhost/GitHub Pages preview. In WordPress: Pages → All Pages → Museum Walk Through (/plan-your-visit/tour-the-museum/museum-walk-through/) → Edit with WPBakery.

  2. 2
    Add a "Raw HTML" element

    Click the + button to add a new element. Search for Raw HTML and add it in the main content column where the 360° viewer should appear. Do not use a Text or Custom HTML element — those strip scripts on WP Engine.

  3. 3
    Copy the walk-through code

    Copy everything between the <!-- START: CMA Museum Walk-Through --> and <!-- END: CMA Museum Walk-Through --> comments. That is the <style>, markup, and <script>. Do not copy this instructions panel.

  4. 4
    Paste into the Raw HTML block

    Paste exactly as-is. No extra wrapper. On WP Engine the widget hides its own heading, uses the page's media library (same-origin), and sits in the theme column.

  5. 5
    Update, then purge WP Engine cache

    Click Update. In WP Engine: Caching → Purge all caches (or the page cache for this URL). Then preview logged-out. Room chips and orange markers should move you between 360° scenes.

⚠ Troubleshooting Tips
  • If the viewer appears but room buttons do nothing, WPBakery/WP Engine stripped the <script> block. Add a Raw JS element and move only the inline script there (leave the Pannellum <script src> in Raw HTML, or let the widget inject it).
  • If you see “360 viewer failed to load,” confirm cdn.jsdelivr.net is not blocked (the live CMA theme already loads Vue from jsDelivr). Check the browser console on the WP Engine URL.
  • Do not iframe or import GitHub Pages in WordPress. If WP says The file https://mattybotstew.github.io/Homepagev2/museum-tour-map/fundamentally-food-kitchen.webp could not be accessed — that is WordPress trying to download a GitHub Pages file. The github.io URL is a preview only. Paste START→END into Raw HTML. Panos already live in the CMA media library at /wp-content/uploads/2026/05/20260430_173004_348-scaled.webp (hyphens in the filename, never fundamentally= food-…).
  • On wpdev / WP Engine staging the widget loads panos from this site's /wp-content/uploads/… (same-origin). Copy production uploads onto that environment if a pano 404s. Do not point WordPress at github.io files.
  • Styles are scoped under .cma-walk so they cannot reset the WP Engine theme.
  • Room order and hotspot yaw/pitch live in the ROOMS array — edit links to retarget orange markers.
ⓘ Media URLs
  • ASSET_MODE defaults to "auto". On childrensmuseumatlanta.org and WP Engine hosts it loads panos from this origin's media library (same-origin). On GitHub Pages / localhost it uses bundled museum-tour-map/ files. No edits needed before pasting into CMA WordPress.
  • Force ASSET_MODE = "cdn" only if you must hotlink production media from a host that is not WP Engine and not the CMA domain (may fail CORS). Use ASSET_MODE = "local" only when the museum-tour-map/ folder is uploaded next to this HTML.
  • Companion floor-plan map widget: public/museum-tour-map.html — same paste pattern.
