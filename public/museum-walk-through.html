WPBakery handoff

  1. Copy everything between the START and END markers above.
  2. Paste into a WPBakery Raw HTML block.
  3. Before pasting on production WordPress, set ASSET_MODE = "cdn" so panoramas hotlink the media library.
  4. Or keep ASSET_MODE = "local" and upload the museum-tour-map/ folder next to this HTML.
