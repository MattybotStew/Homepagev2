How to Add This Map to WPBakery

  1. 1
    Open the Exhibits (or Tour the Museum) page in WordPress

    Navigate to Pages → All Pages, find the destination page, and click Edit with WPBakery.

  2. 2
    Add a "Raw HTML" element

    Click the + button to add a new element. Search for Raw HTML and add it where the interactive map should appear.

  3. 3
    Copy the map code

    Open this HTML file in a text editor. Copy everything between the <!-- START: CMA Museum Tour Map --> and <!-- END: CMA Museum Tour Map --> comments. That gives you the <style>, markup, and <script> together.

  4. 4
    Paste into the Raw HTML block

    Paste the copied code into the Raw HTML element's content area. Do not wrap it in anything else — paste it exactly as-is.

  5. 5
    Save and preview

    Click Update, then preview. Click a pulse point — a 360° viewer should open. Drag to look around. The paste block already includes the Pannellum CDN CSS/JS tags.

⚠ Troubleshooting Tips
  • If the map appears but pins do nothing, WPBakery may be stripping <script> tags. Move the script into a Raw JS element.
  • If you see “360 viewer failed to load,” confirm the Pannellum CDN script is present above the map and not blocked by CSP.
  • Styles are scoped under .cma-tour-map to avoid theme conflicts.
  • Pin positions live in the HOTSPOTS array near the top of the script — edit left / top percentages to nudge pins.
ⓘ Media URLs
  • ASSET_MODE defaults to "auto". On childrensmuseumatlanta.org and WP Engine hosts it loads media from this origin (same-origin). On GitHub Pages / localhost it uses bundled museum-tour-map/ files. No edits needed before pasting into CMA WordPress.
  • Force ASSET_MODE = "cdn" only to hotlink production media from a non-WP-Engine host (may fail CORS). Use ASSET_MODE = "local" when the museum-tour-map/ folder is uploaded next to this HTML. file://, localhost, and GitHub Pages use bundled museum-tour-map/ files.
